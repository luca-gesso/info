# Informatica – Preparazione verifica pratica (4^ Inf)

Inizia da **[GUIDA_STUDIO.md](GUIDA_STUDIO.md)**: schemi da memorizzare, errori classici e piano di studio.

Per allenarti apri **`ripasso_interattivo.html`** nel browser: lezioni spiegate, quiz, "cosa stampa?", trova l'errore, completa il codice ed esercizi con timer.

## Contenuto

| Cartella | Cosa c'è |
|----------|----------|
| `01_compito_risolto/` | Soluzione del compito "Temperature di Ferragosto" (C++), "Analisi frase" (Java), Debug |
| `02_esercizi_tuoi/` | Esercizio tensioni impianto (C++), ContaVocali corretto (Java), "cosa stampa" (ricorsione e ciclo) |
| `03_verifica_simulata/` | Verifica nuova stile prof (`VERIFICA.md`) + `soluzioni/` |

## Compilare ed eseguire

```bash
# C++
g++ tensioni.cpp -o tensioni
./tensioni

# Java (il file deve chiamarsi come la classe public)
javac ContaVocali.java
java ContaVocali
```
